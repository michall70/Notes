`scp` 一次传多个远程目录，关键点是：**通配符要让远程 shell 去展开，所以路径要加引号**。

---

## 1. 最常用：通配符 + 引号

假设狗上的 bag 都叫 `utlidar_bags_*`：

```bash
scp -r "unitree@192.168.123.18:~/utlidar_bags_*" ./
```

注意引号。  
如果不加引号，本地 shell 可能先尝试展开 `~/utlidar_bags_*`，结果匹配不到，就原样传给 scp，容易出问题。加引号后，通配符交给远程 shell 展开，scp 就能收到多个路径。

---

## 2. 明确列出多个目录：花括号

如果你知道具体名字：

```bash
scp -r unitree@192.168.123.18:"{~/bag1,~/bag2,~/bag3}" ./
```

远程 shell 会把它展开成：

```text
~/bag1 ~/bag2 ~/bag3
```

然后 scp 一次传三个。

---

## 3. 更稳的方案：`rsync`

如果本机和狗上都装了 `rsync`，推荐用它：

```bash
rsync -avz --progress "unitree@192.168.123.18:~/utlidar_bags_*" ./
```

好处：

- 有进度条；
- 断点续传；
- 失败重试；
- 可以 `--exclude` 排除文件；
- 传大量小文件比 scp 快。

如果本机没有：

```bash
sudo apt install rsync
```

---

## 4. 高效方案：`tar` 流

目录多、文件碎时，scp 每个文件都要握手，很慢。可以远程打包、本地解包，只走一个连接：

```bash
ssh unitree@192.168.123.18 "tar cf - ~/utlidar_bags_*" | tar xf - -C ./
```

想压缩就加 `z`：

```bash
ssh unitree@192.168.123.18 "tar czf - ~/utlidar_bags_*" | tar xzf - -C ./
```

这样会保留目录结构，直接在当前目录得到所有 bag 文件夹。
