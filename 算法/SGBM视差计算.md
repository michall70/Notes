### 时间复杂度
计算机科学家发明了 **大 O 表示法**，它*忽略具体机器、忽略常数，只关注算法运行时间随输入规模 n 的增长趋势*。
**操作数的估计**

- O(n²) 的意思就是：输入规模是 n，运行时间差不多和 n² 成正比。
- n 只是一个符号，它代表“输入数据的规模”。至于这个“规模”具体指什么，完全由你自己定义，只要保持上下文一致就行。

SGBM 的核心步骤复杂度：
- **代价计算**：O(W × H × D）
- **代价聚合**：O(R × W × H × D) （R 是方向数，8 或 5）
这里的 **W × H 就是总像素数**。
所以你也可以说：
- 令 N = W × H，复杂度为 O(N × D)。
这很明显是**线性的**（相对于像素总数），而不是可怕的 N²。这就是为什么 SGBM 能在普通 CPU 上实时跑 640×480、64 视差的视频。

### sgbm细节
```cpp
cv::Mat disp;
sgbm->compute(leftImg, rightImg, disp);
```

- **`leftImg`, `rightImg`**：必须是已经经过**极线校正**的灰度图（单通道 `CV_8U`）。校正后，左右图像同一物体对应的点会在**同一水平行**上。
- **`disp`**：OpenCV 自动创建的**16位有符号整数**单通道图像，类型是 `CV_16S`（S 表示 signed, 16 位）。每个像素存储的不是直接的视差值，而是**视差值乘以 16** 的结果。

#### 2. 为什么要“乘以 16”保存？

这是为了**用整数来存储亚像素精度的小数**。  
真正的视差值可能带有小数，例如某点的视差是 12.75 像素。如果直接用整数存，那就只能得到 13，损失了精度。  

因此，SGBM 内部会把计算出的浮点视差 **乘以 16，然后四舍五入存成整数**。  
16 = 2⁴，相当于保留 4 位二进制小数，精度达到 1/16 = 0.0625 像素。  
这样既节省内存，又能保留较高精度。

#### 3. `dispF32 /= 16.0f` 就是把这个“浓缩”的数据还原

```cpp
disp.convertTo(dispF32, CV_32F);  // 先转成 32 位浮点数
dispF32 /= 16.0f;                 // 再除以 16，得到真实的浮点视差值
```

- **`convertTo(dispF32, CV_32F)`**  
  把 `CV_16S` 的整数视差图复制并转为 `CV_32F` 浮点数矩阵。此时矩阵里的数值还没还原，比如一个像素值是 `204`，转成 `float` 后还是 `204.0`，但真实视差应该是 `204/16 = 12.75`。
- **`dispF32 /= 16.0f`**  
  整个矩阵每个像素都除以 16，得到真正的视差值（单位：像素）。

> **补充说明**  
> 如果你的 `sgbm` 参数里 `minDisparity` 设为 0（你代码里就是 0），那么**无效像素**会被 SGBM 标记为 `(minDisparity - 1) * 16 = -16`。除以 16 后，这些区域的值就是 **-1**。  
> 因此，在后续计算深度时，可以直接用 `if (dispF32.at<float>(y,x) <= 0.0f) continue;` 来跳过无效点。


### 裁剪无效区域，保留共同视窗
利用 OpenCV 的函数**动态查找所有有效像素的包围框**，然后裁剪。  
代码清晰，适合相机参数不准确或图像已经经过裁剪的场景。

```cpp
// 假设 dispF32 已经除以 16，无效值为 -1 或 <=0
cv::Mat mask = (dispF32 > 0);   // 有效视差必须大于 0

// 找到所有非零像素点的包围矩形
cv::Rect roi = cv::boundingRect(mask);
// roi.x, roi.y 是矩形左上角，roi.width, roi.height 是宽高

// 裁剪深度图 (假设已经算出 depth32F)
cv::Mat depth_cropped = depth32F(roi);
```

**原理**：  
`cv::boundingRect` 会扫描二值图像（`mask`），找出所有白色（值>0）像素的横纵坐标范围，然后返回一个能恰好包裹它们的正矩形。这个矩形就是**共同视野的有效区域**，边缘的无效部分被自动裁掉了。

**举例**：  
原始图像 640×480，视差图左侧 0~80 列全是 -1，右侧 600~639 列也全是 -1。  
- 有效像素的 x 范围是 81 ~ 599。  
- `boundingRect` 会得到 `roi = {x:81, y:0, width:518, height:480}`。  
然后深度图只取这部分，就完美去掉了边缘。
