# Ubuntu 创建应用快捷方式（.desktop + Dash 固定）

1. **创建 `.desktop` 文件**  
   `~/.local/share/applications/<name>.desktop`

2. **最小模板**  
   ```ini
[Desktop Entry]
Type=Application
Name=MyApp
Exec=/绝对路径/可执行文件
Icon=/绝对路径/图标.png
Terminal=false
Categories=Development;   # 可选
Path=/工作目录          # 可选，修复 AppImage 路径问题
StartupWMClass=窗口类名   # 可选，正确合并 Dock 图标
   ```

3. **赋予执行权限**  
   `chmod +x ~/.local/share/applications/<name>.desktop`

4. **刷新菜单**  
   `update-desktop-database ~/.local/share/applications/`

5. **固定到 Dash**  
   按 `Win` → 搜索应用名 → 右键 → “添加到收藏夹”

## AppImage 沙箱错误处理

**错误日志**  
`chrome-sandbox` 权限问题 → **添加 `--no-sandbox`**  
```ini
Exec=/path/to/app.AppImage --no-sandbox
```

**或（推荐）** 开启用户命名空间：  
`sudo sysctl -w kernel.unprivileged_userns_clone=1`

## 常用路径
- 用户应用目录：`~/.local/share/applications/`
- 用户图标目录：`~/.local/share/icons/`
