# 深度图的获取与无深度图的解决方案

## 一、深度图如何获得

### 1. RGB-D相机直接获取（最常见）

ACE-SLAM是**RGB-D SLAM**系统，假设输入包含深度图。深度相机主要有两种技术：

#### (1) 结构光（Structured Light）
- **代表设备**：Kinect v1、RealSense D435i
- **原理**：投射已知图案到场景，通过图案变形计算深度
- **优点**：室内精度高
- **缺点**：室外受阳光干扰，距离有限（通常<10m）

#### (2) 飞行时间（Time-of-Flight, ToF）
- **代表设备**：Azure Kinect、Kinect v2、RealSense L515
- **原理**：发射红外光，测量光往返时间计算深度
- **优点**：室外可用，距离更远
- **缺点**：分辨率较低，功耗大

#### (3) 双目深度相机
- **代表设备**：RealSense D455、ZED 2i
- **原理**：两个RGB相机，通过立体匹配计算视差，再转换为深度
- **优点**：室外可用，无需主动光源
- **缺点**：需要纹理，计算量大

**数据格式**：
```python
# 深度图通常是16位PNG，单位：毫米
depth_raw = cv2.imread("depth.png", cv2.IMREAD_UNCHANGED)  # uint16
depth_meters = depth_raw.astype(np.float32) / 1000.0        # 转换为米

# 或者是32位浮点PNG，单位：米
depth_meters = cv2.imread("depth.png", cv2.IMREAD_UNCHANGED)  # float32
```

### 2. 双目视觉计算得到

如果你有两个RGB相机（双目系统），可以通过立体匹配计算深度：

```python
# OpenCV双目深度计算
stereo = cv2.StereoSGBM_create(
    minDisparity=0,
    numDisparities=128,
    blockSize=5
)
disparity = stereo.compute(img_left, img_right)

# 从视差转换为深度
# Z = baseline * focal_length / disparity
baseline = 0.11  # 双目基线长度（米）
fx = 600.0       # 焦距（像素）
depth = baseline * fx / (disparity + 1e-6)  # 米
```

**数学原理**：
```
视差 d = x_left - x_right （同一3D点在左右图像中的x坐标差）

深度 Z = f × B / d

其中:
f = 焦距（像素）
B = 基线长度（两个相机之间的距离）
```

### 3. 单目深度估计（MONO）

如果只有一个RGB相机，可以用**深度估计网络**预测深度：

**常用方法**：
| 方法 | 类型 | 精度 | 速度 |
|------|------|------|------|
| MiDaS | 自监督 | 中等 | 快 |
| DPT | 有监督 | 较高 | 中等 |
| Depth Anything | 自监督 | 高 | 快 |
| ZoeDepth | 有监督 | 高 | 中等 |

**代码示例**：
```python
import torch
from midas.dpt_depth import DPTDepthModel

# 加载预训练模型
model = DPTDepthModel.backbone="vitb21")
model.load_state_dict(torch.load("weights/dpt_large.pth"))
model.eval()

# 推理
with torch.no_grad():
    depth_pred = model(rgb_tensor)  # 输出：相对深度图

# 注意：单目估计的是相对深度，需要尺度对齐
# 如果要用于SLAM，需要额外处理
```

**问题**：
- 输出的是**相对深度**（Scale Ambiguity），不是绝对深度
- 需要与真实尺度对齐才能用于SLAM
- 精度不如RGB-D相机

### 4. LiDAR获取

**设备**：Velodyne、Ouster、Livox等

**特点**：
- 精度高，室外远距离
- 点云稀疏（vs 深度图稠密）
- 通常用于自动驾驶

**转换为深度图**：
```python
# LiDAR点云转深度图
# 假设point_cloud是N×3的点云 [X, Y, Z]
depth_image = np.zeros((H, W), dtype=np.float32)

for point in point_cloud:
    X, Y, Z = point
    # 投影到图像平面
    u = fx * X / Z + cx
    v = fy * Y / Z + cy
    u, v = int(u), int(v)
    if 0 <= u < W and 0 <= v < H:
        depth_image[v, u] = Z  # 深度就是Z坐标
```

## 二、如果没有深度图怎么办

### 方案1：使用ACE-Zero方法（论文推荐）

ACE-SLAM论文提到了**ACE-Zero** [brachmann2024acezero]，它可以在**没有深度图**的情况下工作：

**原理**：
1. 使用单目深度估计网络生成伪深度
2. 用伪深度训练SCR网络
3. 通过自监督不断优化深度估计

**流程**：
```
RGB图像
    ↓
单目深度估计网络 → 伪深度图
    ↓
反投影到3D → 伪3D点云
    ↓
训练TriMLP（初始）
    ↓
重定位 → 优化位姿
    ↓
用优化后的位姿优化深度估计
    ↓
循环迭代
```

**论文原话**：
> "Future extensions could incorporate depth to produce true RGB-D features or even leverage depth priors, as in ACEZero, enabling operation on RGB-only streams."

### 方案2：使用其他SLAM系统估计深度

用一个**纯视觉SLAM**先跑一遍，获取位姿和稀疏深度：

```python

import orbslam3

slam = orbslam3.System(vocab_path, settings_path, orbslam3.Sensor.MONOCULAR)
slam.initialize()

# 处理每一帧
for frame_id in range(num_frames):
    pose = slam.process_image_mono(image, timestamp)
    # 从地图点获取稀疏深度
    points = slam.get_tracked_map_points()
```

**然后**：
- 稀疏深度可以用于初始化SCR网络
- 后续通过自监督优化

### 方案3：使用双目视觉

如果你有双目相机，可以直接计算深度：

```python
class StereoDepthEstimator:
    def __init__(self, baseline, fx, fy, cx, cy):
        self.baseline = baseline
        self.fx = fx
        self.fy = fy
        self.cx = cx
        self.cy = cy
        
        self.stereo = cv2.StereoSGBM_create(
            minDisparity=0,
            numDisparities=128,
            blockSize=5,
            P1=8 * 3 * 5**2,
            P2=32 * 3 * 5**2
        )
    
    def compute_depth(self, img_left, img_right):
        # 计算视差
        disparity = self.stereo.compute(img_left, img_right).astype(np.float32) / 16.0
        
        # 转换为深度
        depth = self.baseline * self.fx / (disparity + 1e-6)
        
        # 处理无效值
        depth[disparity <= 0] = 0
        depth[depth > 10.0] = 0  # 过滤远处噪声
        
        return depth
```

## 三、深度图质量的重要性

深度图的质量直接影响SLAM效果：

| 深度图问题 | 对SLAM的影响 | 解决方案 |
|-----------|-------------|---------|
| **噪声** | 3D坐标不准，位姿估计漂移 | 滤波（中值/高斯） |
| **空洞** | 部分区域无特征，建图不完整 | 插值或忽略 |
| **量化误差** | 近处精度高，远处精度低 | 使用浮点深度图 |
| **运动模糊** | 深度值错误 | 时间同步，减少运动 |
| **尺度模糊** | 单目深度的固有问题 | 需要额外标定 |

**预处理示例**：
```python
def preprocess_depth(depth, min_depth=0.1, max_depth=10.0):
    """深度图预处理"""
    # 1. 过滤无效值
    depth[depth < min_depth] = 0
    depth[depth > max_depth] = 0
    
    # 2. 中值滤波去噪
    depth_filtered = cv2.medianBlur(depth, 5)
    
    # 3. 填补小空洞
    depth_filled = cv2.inpaint(depth_filtered, 
                                mask=(depth_filtered == 0).astype(np.uint8),
                                inpaintRadius=3, 
                                flags=cv2.INPAINT_NS)
    
    return depth_filled
```

# 双目深度估计：从SGBM到深度学习方法

## 一、SGBM效果不好的常见原因

在介绍更好的方法之前，先分析SGBM效果差的可能原因：

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| **弱纹理区域** | 白墙、天空等区域匹配失败 | 使用深度学习方法 |
| **遮挡区域** | 左图可见但右图不可见 | 使用全局优化方法 |
| **重复纹理** | 栅栏、瓷砖等重复图案 | 增加上下文信息 |
| **参数不当** | numDisparities、blockSize设置不合理 | 需要针对场景调参 |
| **标定不准** | 相机内参/外参有误差 | 重新标定 |

## 二、推荐的深度学习方法（按效果排序）

### 方法1：FoundationStereo（推荐 - 最新最强）

**来源**：NVIDIA，CVPR 2025最佳论文提名

**特点**：
- **零样本泛化**：不需要在你的数据上微调
- **精度最高**：在多个基准测试上达到SOTA
- **鲁棒性强**：对弱纹理、遮挡、光照变化都有效

**安装**：
```bash
git clone https://github.com/NVlabs/FoundationStereo.git
cd FoundationStereo
conda env create -f environment.yml
conda activate foundstereo
# 下载预训练权重
bash scripts/download_models.sh
```

**使用方法**：
```python
import torch
import cv2
import numpy as np
from core.utils.utils import InputPadder
from core.foundation_stereo import foundation_stereo

# 加载模型
model = foundation_stereo(pretrained="checkpoints/foundstereo.pth")
model.eval().cuda()

def estimate_depth_stereo(img_left, img_right):
    """使用FoundationStereo估计深度"""
    # 预处理
    img_left_tensor = torch.from_numpy(img_left).permute(2, 0, 1).float().unsqueeze(0) / 255.0
    img_right_tensor = torch.from_numpy(img_right).permute(2, 0, 1).float().unsqueeze(0) / 255.0
    
    # 填充到8的倍数
    padder = InputPadder(img_left_tensor.shape, divis_by=8)
    img_left_tensor, img_right_tensor = padder.pad(img_left_tensor, img_right_tensor)
    
    # 推理
    with torch.no_grad():
        disp = model(img_left_tensor.cuda(), img_right_tensor.cuda())
    
    # 反填充
    disp = padder.unpad(disp)
    
    # 转换为深度
    # Z = baseline * fx / disparity
    baseline = 0.11  # 你的双目基线（米）
    fx = 600.0       # 你的焦距（像素）
    depth = baseline * fx / (disp.cpu().numpy() + 1e-6)
    
    return depth, disp.cpu().numpy()
```

## 三、完整的工作流程

### 步骤1：相机标定（如果还没做）

```python
import cv2
import numpy as np

# 棋盘格标定
def calibrate_stereo(images_left, images_right, board_size=(9, 6), square_size=0.025):
    """
    双目标定
    
    参数:
        images_left: 左相机图像列表
        images_right: 右相机图像列表
        board_size: 棋盘格内角点数
        square_size: 格子大小（米）
    
    返回:
        K_left, K_right: 内参矩阵
        D_left, D_right: 畸变系数
        R, T: 右相机相对于左相机的旋转和平移
    """
    obj_points = []  # 3D世界坐标
    img_points_left = []  # 左图2D坐标
    img_points_right = []  # 右图2D坐标
    
    # 准备棋盘格3D坐标
    objp = np.zeros((board_size[0] * board_size[1], 3), np.float32)
    objp[:, :2] = np.mgrid[0:board_size[0], 0:board_size[1]].T.reshape(-1, 2)
    objp *= square_size
    
    for img_l, img_r in zip(images_left, images_right):
        gray_l = cv2.cvtColor(img_l, cv2.COLOR_BGR2GRAY)
        gray_r = cv2.cvtColor(img_r, cv2.COLOR_BGR2GRAY)
        
        ret_l, corners_l = cv2.findChessboardCorners(gray_l, board_size, None)
        ret_r, corners_r = cv2.findChessboardCorners(gray_r, board_size, None)
        
        if ret_l and ret_r:
            # 亚像素精度
            criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
            corners_l = cv2.cornerSubPix(gray_l, corners_l, (11, 11), (-1, -1), criteria)
            corners_r = cv2.cornerSubPix(gray_r, corners_r, (11, 11), (-1, -1), criteria)
            
            obj_points.append(objp)
            img_points_left.append(corners_l)
            img_points_right.append(corners_r)
    
    # 单目标定
    ret_l, K_left, D_left, rvecs_l, tvecs_l = cv2.calibrateCamera(
        obj_points, img_points_left, gray_l.shape[::-1], None, None)
    ret_r, K_right, D_right, rvecs_r, tvecs_r = cv2.calibrateCamera(
        obj_points, img_points_right, gray_r.shape[::-1], None, None)
    
    # 双目标定
    flags = cv2.CALIB_FIX_INTRINSIC
    criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 100, 1e-5)
    ret, K_left, D_left, K_right, D_right, R, T, E, F = cv2.stereoCalibrate(
        obj_points, img_points_left, img_points_right,
        K_left, D_left, K_right, D_right,
        gray_l.shape[::-1], criteria=criteria, flags=flags)
    
    return K_left, D_left, K_right, D_right, R, T
```

### 步骤2：图像校正

```python
def stereo_rectify(K_left, D_left, K_right, D_right, R, T, image_size):
    """
    立体校正
    
    返回:
        R1, R2: 左右相机的校正旋转矩阵
        P1, P2: 左右相机的投影矩阵
        Q: 视差到深度的映射矩阵
        roi1, roi2: 有效区域
    """
    R1, R2, P1, P2, Q, roi1, roi2 = cv2.stereoRectify(
        K_left, D_left, K_right, D_right,
        image_size, R, T,
        alpha=0,  # 0=裁剪, 1=保留所有
        flags=cv2.CALIB_ZERO_DISPARITY
    )
    
    # 计算映射表
    map1_left, map2_left = cv2.initUndistortRectifyMap(
        K_left, D_left, R1, P1, image_size, cv2.CV_32FC1)
    map1_right, map2_right = cv2.initUndistortRectifyMap(
        K_right, D_right, R2, P2, image_size, cv2.CV_32FC1)
    
    return map1_left, map2_left, map1_right, map2_right, Q

def rectify_images(img_left, img_right, map1_left, map2_left, map1_right, map2_right):
    """应用校正映射"""
    rectified_left = cv2.remap(img_left, map1_left, map2_left, cv2.INTER_LINEAR)
    rectified_right = cv2.remap(img_right, map1_right, map2_right, cv2.INTER_LINEAR)
    return rectified_left, rectified_right
```

### 步骤3：深度估计

```python
class StereoDepthEstimator:
    def __init__(self, method="foundation_stereo", baseline=0.11, fx=600.0):
        """
        双目深度估计器
        
        参数:
            method: "foundation_stereo", "raft_stereo", "crestereo", "sgbm"
            baseline: 双目基线（米）
            fx: 焦距（像素）
        """
        self.method = method
        self.baseline = baseline
        self.fx = fx
        
        if method == "foundation_stereo":
            self.model = self._load_foundation_stereo()
        elif method == "raft_stereo":
            self.model = self._load_raft_stereo()
        elif method == "crestereo":
            self.model = self._load_crestereo()
    
    def estimate(self, img_left, img_right):
        """估计深度图"""
        if self.method == "foundation_stereo":
            return self._estimate_foundation_stereo(img_left, img_right)
        elif self.method == "raft_stereo":
            return self._estimate_raft_stereo(img_left, img_right)
        elif self.method == "crestereo":
            return self._estimate_crestereo(img_left, img_right)
        elif self.method == "sgbm":
            return self._estimate_sgbm(img_left, img_right)
    
    def _estimate_sgbm(self, img_left, img_right):
        """SGBM方法（基准对比）"""
        gray_left = cv2.cvtColor(img_left, cv2.COLOR_BGR2GRAY)
        gray_right = cv2.cvtColor(img_right, cv2.COLOR_BGR2GRAY)
        
        stereo = cv2.StereoSGBM_create(
            minDisparity=0,
            numDisparities=128,
            blockSize=5,
            P1=8 * 3 * 5**2,
            P2=32 * 3 * 5**2,
            disp12MaxDiff=1,
            uniquenessRatio=10,
            speckleWindowSize=100,
            speckleRange=32,
            preFilterCap=63,
            mode=cv2.STEREO_SGBM_MODE_SGBM_3WAY
        )
        
        disparity = stereo.compute(gray_left, gray_right).astype(np.float32) / 16.0
        
        # WLS滤波（可选，效果更好）
        wls_filter = cv2.ximgproc.createDisparityWLSFilter(stereo)
        right_matcher = cv2.ximgproc.createRightMatcher(stereo)
        disparity_right = right_matcher.compute(gray_right, gray_left)
        disparity = wls_filter.filter(disparity, img_left, disparity_right=disparity_right)
        
        # 转换为深度
        depth = self.baseline * self.fx / (disparity + 1e-6)
        depth[disparity <= 0] = 0
        depth[depth > 10.0] = 0
        
        return depth, disparity
```

```python
class SLAMStereoDepth:
    """为SLAM优化的双目深度估计"""
    
    def __init__(self, baseline, fx, fy, cx, cy):
        self.baseline = baseline
        self.fx = fx
        self.fy = fy
        self.cx = cx
        self.cy = cy
        
        # 加载FoundationStereo
        from core.foundation_stereo import foundation_stereo
        self.model = foundation_stereo(pretrained="checkpoints/foundstereo.pth")
        self.model.eval().cuda()
        
        # 深度滤波器
        self.depth_filter = DepthFilter()
    
    def get_depth_for_slam(self, img_left, img_right):
        """获取SLAM可用的深度图"""
        # 1. 深度估计
        disparity = self._estimate_disparity(img_left, img_right)
        
        # 2. 转换为深度
        depth = self.baseline * self.fx / (disparity + 1e-6)
        
        # 3. 后处理
        depth = self._postprocess(depth)
        
        # 4. 质量评估
        quality = self._assess_quality(depth)
        
        return depth, quality
    
    def _postprocess(self, depth):
        """深度图后处理"""
        # 1. 去除异常值
        depth[depth < 0.1] = 0  # 太近
        depth[depth > 10.0] = 0  # 太远
        
        # 2. 中值滤波
        depth_filtered = cv2.medianBlur(depth, 5)
        
        # 3. 填补小空洞（可选）
        depth_filled = self._fill_small_holes(depth_filtered)
        
        return depth_filled
    
    def _assess_quality(self, depth):
        """评估深度图质量"""
        valid_pixels = np.sum(depth > 0)
        total_pixels = depth.shape[0] * depth.shape[1]
        coverage = valid_pixels / total_pixels
        
        # 深度统计
        valid_depth = depth[depth > 0]
        if len(valid_depth) > 0:
            mean_depth = np.mean(valid_depth)
            std_depth = np.std(valid_depth)
        else:
            mean_depth = 0
            std_depth = 0
        
        return {
            "coverage": coverage,
            "mean_depth": mean_depth,
            "std_depth": std_depth,
            "num_valid": valid_pixels
        }
```
