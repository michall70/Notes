## 1. 两种坐标系

### 1.1 局部坐标（相机坐标系）

```
深度图反投影得到的是相机坐标系下的3D点：

给定:
- 像素坐标: x_i = (u, v)
- 深度值: d_i
- 相机内参: K = [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]

反投影公式:
y_i = π_K^{-1}(x_i, d_i) = [(u-cx)*d_i/fx, (v-cy)*d_i/fy, d_i]

这个y_i是在相机坐标系下的3D坐标
```

**图示**：
```
世界坐标系
    ↑
    |   相机坐标系
    |   ↑
    |   |  y_i (局部坐标)
    |   | /
    |   |/____→
    |  /相机
    | /
    |/_______________→
    
y_i: 相机看到这个点在自己的"正前方"某个位置
```

### 1.2 全局坐标（世界坐标系）

```
TriMLP预测的是世界坐标系下的3D点：

给定:
- 特征向量: f_i

预测:
ŷ_i = M(f_i)

这个ŷ_i是在世界坐标系下的3D坐标
```

**图示**：
```
世界坐标系
    ↑
    |   ŷ_i (全局坐标)
    |   *
    |   
    |   
    |   
    |_______________→
    
ŷ_i: 这个点在世界中的真实位置
```

## 2. 位姿的定义

相机位姿 P ∈ SE(3) 表示**从相机坐标系到世界坐标系的变换**：

```
P = [R | t]  其中:
    [0 | 1]
    
R: 3×3 旋转矩阵
t: 3×1 平移向量

变换关系:
y_world = P * y_camera = R * y_camera + t
```

**图示**：
```
世界坐标系
    ↑
    |     ŷ_i (全局坐标)
    |     *
    |    /
    |   / P (位姿)
    |  /
    | / y_i (局部坐标)
    |/_______________→
    相机

ŷ_i = P * y_i = R * y_i + t
```

## 3. 重定位的数学问题

### 3.1 问题描述

已知：
- 一组局部坐标：`{y_i}_{i=1}^N`（从深度图反投影）
- 对应的全局坐标预测：`{ŷ_i}_{i=1}^N`（从TriMLP）

求解：
- 位姿 `P = [R | t]`，使得 `ŷ_i ≈ P * y_i` 对所有i成立

### 3.2 数学公式

```
最小化目标函数:

P* = argmin_{P ∈ SE(3)} Σ_{i=1}^N ||ŷ_i - P * y_i||^2
   = argmin_{P ∈ SE(3)} Σ_{i=1}^N ||ŷ_i - (R * y_i + t)||^2
```

## 4. 与ICP的对比

### 4.1 ICP（Iterative Closest Point）

```
输入:
- 点集A: {a_i}（源点云）
- 点集B: {b_i}（目标点云）

目标:
- 找到位姿P，使得P*A尽可能接近B

步骤:
1. 对A中的每个点，在B中找最近邻
2. 用匹配好的点对求解位姿
3. 用求解的位姿变换A
4. 重复1-3直到收敛
```

### 4.2 aceSLAM重定位

```
输入:
- 局部坐标: {y_i}（从深度图，固定不变）
- 全局坐标预测: {ŷ_i}（从TriMLP，固定不变）

目标:
- 找到位姿P，使得P*y_i ≈ ŷ_i

关键区别:
- 不需要迭代找最近邻！
- 因为特征已经隐式建立了对应关系:
  同一个特征f_i，既有局部坐标y_i，又有全局坐标ŷ_i
  它们天然就是对应的！
```

### 4.3 对比总结

| 特性 | ICP | aceSLAM重定位 |
|------|-----|---------------|
| 对应关系 | 需要迭代最近邻搜索 | 已知（通过特征） |
| 输入 | 两组3D点 | 3D点对（通过特征关联） |
| 计算量 | O(N²) 或 O(N log N) | O(N) |
| 鲁棒性 | 可能陷入局部最优 | 更稳定 |

## 5. 求解方法：Kabsch-Umeyama算法

这是一个经典的**点集配准**问题，有闭式解。

### 5.1 问题形式化

```
给定N对点:
源点: {y_i}_{i=1}^N  (局部坐标)
目标: {ŷ_i}_{i=1}^N  (全局坐标)

求解: R, t 使得 Σ ||ŷ_i - (R*y_i + t)||^2 最小
```

### 5.2 求解步骤

```python
import numpy as np

def kabsch_algorithm(source, target):
    """
    Kabsch算法：求解最优刚体变换
    
    参数:
        source: 源点集 (N, 3) - 局部坐标
        target: 目标点集 (N, 3) - 全局坐标
    
    返回:
        R: 旋转矩阵 (3, 3)
        t: 平移向量 (3,)
    """
    N = source.shape[0]
    
    # 步骤1: 计算质心
    source_center = source.mean(axis=0)  # (3,)
    target_center = target.mean(axis=0)  # (3,)
    
    # 步骤2: 去中心化
    source_centered = source - source_center  # (N, 3)
    target_centered = target - target_center  # (N, 3)
    
    # 步骤3: 计算协方差矩阵
    H = source_centered.T @ target_centered  # (3, 3)
    
    # 步骤4: SVD分解
    U, S, Vt = np.linalg.svd(H)
    
    # 步骤5: 确保右手坐标系
    d = np.linalg.det(Vt.T @ U.T)
    if d < 0:
        Vt[-1, :] *= -1
    
    # 步骤6: 计算旋转和平移
    R = Vt.T @ U.T  # (3, 3)
    t = target_center - R @ source_center  # (3,)
    
    return R, t
```

### 5.3 数学推导

```
目标函数:
J(R, t) = Σ_i ||ŷ_i - (R*y_i + t)||^2

展开:
J = Σ_i (ŷ_i - R*y_i - t)^T (ŷ_i - R*y_i - t)

对t求导并令其为0:
∂J/∂t = -2 Σ_i (ŷ_i - R*y_i - t) = 0
→ t = (1/N) Σ_i ŷ_i - R * (1/N) Σ_i y_i
→ t = ŷ_center - R * y_center

其中 ŷ_center, y_center 是质心

将t代入，去中心化后:
J = Σ_i ||ŷ_i' - R*y_i'||^2

其中 ŷ_i' = ŷ_i - ŷ_center, y_i' = y_i - y_center

对R求解（使用SVD）:
H = Σ_i y_i' * ŷ_i'^T  (协方差矩阵)
H = U * S * V^T  (SVD分解)
R = V * U^T  (如果det(R) > 0)
```

## 6. RANSAC处理外点

由于TriMLP的预测可能有错误，需要RANSAC：

```python
def ransac_relocalization(y_hat, y_local, num_hypotheses=128, 
                          inlier_threshold=0.05):
    """
    RANSAC重定位
    
    参数:
        y_hat: 预测的全局坐标 (N, 3)
        y_local: 局部坐标 (N, 3)
        num_hypotheses: 候选位姿数量
        inlier_threshold: 内点阈值（米）
    
    返回:
        best_pose: 最佳位姿 (4, 4)
        best_inlier_ratio: 最佳内点比例
    """
    N = y_hat.shape[0]
    best_pose = None
    best_inlier_ratio = 0
    best_num_inliers = 0
    
    for _ in range(num_hypotheses):
        # 步骤1: 随机采样3个点对
        # （3个点足以确定一个刚体变换）
        indices = np.random.choice(N, 3, replace=False)
        y_sample = y_local[indices]   # (3, 3)
        y_hat_sample = y_hat[indices] # (3, 3)
        
        # 步骤2: 用Kabsch算法求解位姿
        R, t = kabsch_algorithm(y_sample, y_hat_sample)
        
        # 构造4x4齐次变换矩阵
        pose = np.eye(4)
        pose[:3, :3] = R
        pose[:3, 3] = t
        
        # 步骤3: 计算所有点的残差
        # y_hat ≈ P * y_local
        y_hat_pred = (R @ y_local.T).T + t  # (N, 3)
        errors = np.linalg.norm(y_hat_pred - y_hat, axis=1)  # (N,)
        
        # 步骤4: 计算内点比例
        inliers = errors < inlier_threshold
        inlier_ratio = inliers.mean()
        
        # 步骤5: 更新最佳假设
        if inlier_ratio > best_inlier_ratio:
            best_inlier_ratio = inlier_ratio
            best_num_inliers = inliers.sum()
            best_pose = pose
            best_inlier_mask = inliers
    
    # 步骤6: 用所有内点重新估计位姿（更精确）
    if best_num_inliers > 3:
        R, t = kabsch_algorithm(y_local[best_inlier_mask], 
                                 y_hat[best_inlier_mask])
        best_pose = np.eye(4)
        best_pose[:3, :3] = R
        best_pose[:3, 3] = t
    
    return best_pose, best_inlier_ratio
```

## 7. 完整的重定位流程图

```
输入:
├── RGB图像 I^t
├── 深度图 D^t
└── 相机内参 K

        ↓
┌───────────────────────────────────────┐
│  步骤1: 特征提取                       │
│  f_i = FeatureExtractor(I^t)          │
│  x_i = 像素坐标                       │
│  d_i = 从D^t读取深度                   │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│  步骤2: 反投影到局部坐标               │
│  y_i = π_K^{-1}(x_i, d_i)            │
│  = [(u-cx)*d/fx, (v-cy)*d/fy, d]    │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│  步骤3: TriMLP预测全局坐标             │
│  ŷ_i = M(f_i)                         │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│  步骤4: RANSAC求解位姿                 │
│  对每组采样:                           │
│    - 采样3个点对                       │
│    - Kabsch算法求解R, t               │
│    - 计算内点比例                      │
│  选择内点比例最高的位姿                │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│  步骤5: 用内点精化位姿                 │
│  只用内点重新计算R, t                  │
└───────────────────────────────────────┘
        ↓
输出:
├── 相机位姿 P^t = [R|t] (4×4矩阵)
└── 内点比例 λ^t ∈ [0, 1]
```

## 8. 关键洞察

### 8.1 为什么特征能建立对应关系？

```
传统SLAM:
- 特征只用于帧间匹配
- 需要显式的特征匹配步骤

aceSLAM:
- 特征同时关联局部坐标和全局坐标
- 同一个特征f_i:
  - 从深度图得到: f_i ↔ y_i (局部)
  - 从TriMLP得到: f_i ↔ ŷ_i (全局)
- 因此: y_i ↔ ŷ_i 天然对应！

这就是为什么不需要迭代最近邻搜索
```

### 8.2 TriMLP的作用

```
TriMLP本质上是一个"字典":
- 输入: 特征描述子
- 输出: 世界坐标

训练好的TriMLP:
- 对于同一个3D点，无论从哪个角度看
- 只要提取的特征相似
- 就会预测出相似的全局坐标

这使得重定位成为可能
```

## 9. 总结

| 步骤 | 操作 | 输入 | 输出 |
|------|------|------|------|
| 1 | 特征提取 | RGB图像 | 特征向量{f_i} |
| 2 | 反投影 | 深度图+内参 | 局部坐标{y_i} |
| 3 | 坐标预测 | 特征向量 | 全局坐标{ŷ_i} |
| 4 | RANSAC | 点对{(y_i, ŷ_i)} | 位姿P^t |
| 5 | 精化 | 内点子集 | 精确位姿P^t |

核心思想：**通过特征建立2D像素→3D全局坐标的映射，再与深度图得到的3D局部坐标对齐，求解相机位姿**。

这与ICP的思路类似，但避免了迭代最近邻搜索，因为对应关系已经通过特征隐式建立了。
