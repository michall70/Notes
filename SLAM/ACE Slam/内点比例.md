## 内点比例 $\lambda^t$ 的完整定义

### 1. 数学定义

在RANSAC位姿估计过程中，对于**一个候选位姿假设** $\mathbf{P}$，内点比例定义为：

$$
\lambda^t(\mathbf{P}) = \frac{1}{N} \sum_{i=1}^{N} \mathbf{1}\big(r_i^t(\mathcal{M}, \mathbf{P}) < \tau\big)
$$

其中：

- $N$：该帧的特征总数
- $\tau$：内点判定阈值（论文中为0.05米，即5厘米）
- $\mathbf{1}(\cdot)$：指示函数（条件为真时取1，否则取0）
- $r_i^t(\mathcal{M}, \mathbf{P})$：第 $i$ 个特征的**重投影残差**

而残差 $r_i^t$ 的定义为：

$$
r_i^t(\mathcal{M}, \mathbf{P}) = \big\|\underbrace{\mathcal{M}(\mathbf{f}_i^t)}_{\text{TriMLP预测的全局坐标}} - \underbrace{\mathbf{P} \mathbf{y}_i^t}_{\text{局部坐标变换到全局}}\big\|^2
$$

展开就是：

$$
r_i^t(\mathcal{M}, \mathbf{P}) = \big\|\underbrace{\hat{\mathbf{y}}_i^t}_{\text{TriMLP输出}} - \underbrace{(\mathbf{R} \cdot \mathbf{y}_i^t + \mathbf{t})}_{\text{深度反投影} \atop \text{乘以位姿}}\big\|^2
$$

### 2. 完整过程：$\lambda^t$ 是如何产出的？

```
一帧到来时：
┌──────────────────────────────────────────────────────┐
│ 1. 特征提取 → f_i^t                                   │
│ 2. TriMLP预测 → ŷ_i^t = M(f_i^t)  （所有N个特征）     │
│ 3. 深度反投影 → y_i^t（相机坐标系下的局部坐标）         │
│                                                       │
│ 4. RANSAC开始：                                        │
│    │                                                    │
│    ├─ 假设k=1: 随机采样3个点对                           │
│    │  → Kabsch算法 → 得到候选位姿 P_k                   │
│    │  → 计算所有N个点的残差 r_i^t(M, P_k)               │
│    │  → 统计残差<τ的比例 → λ^t(P_k)                    │
│    │                                                    │
│    ├─ 假设k=2: 再随机采样3个点对                        │
│    │  → 得到 P_k, λ^t(P_k)                              │
│    │                                                    │
│    ├─ ...重复最多H=128次                                │
│    │                                                    │
│    └─ 选择 λ^t 最高的假设：                              │
│       P^t = argmax λ^t(P_k)                             │
│       k                                                 │
│       λ^t = max λ^t(P_k)  ← 这就是最终存储的 λ^t       │
│                         ← 这个帧的"内点比例"            │
│                                                       │
│ 5. 输出：P^t（位姿），λ^t（内点比例）                    │
└──────────────────────────────────────────────────────┘
```

**所以 $\lambda^t$ 是RANSAC完成后，最佳候选位姿对应的那个内点比例。**

### 3. $\lambda^t$ 是何时产出的？—— 三个时间点

```python
λ^t 在三个时间点被计算或更新：

┌────────────────────────────────────────────────────────────┐
│ 时间点1: 帧首次到来时                                      │
│ 帧进入系统 → 第一次RANSAC → 产出 λ^t_initial              │
│ 这个值决定了:                                               │
│   - 帧是否成为关键帧 (λ < 0.5 → 质量差 → 成为关键帧)       │
│   - 后续该帧特征被采样的概率 (λ 低 → 采样概率大)           │
├────────────────────────────────────────────────────────────┤
│ 时间点2: 在优化窗口中重新定位时（每个优化周期）              │
│ TriMLP已经更新 → 重新预测ŷ_i → 重新RANSAC → 新λ^t        │
│ 原因: TriMLP变好了 → 旧的位姿和λ不再准确                   │
│ 结果: λ^t 只会上升（因为预测更准了）                       │
├────────────────────────────────────────────────────────────┤
│ 时间点3: 永远不再被采样到的帧 → λ^t 冻结，不再更新        │
│ 影响: 它之后在优化窗口中的采样概率由静止的λ^t决定           │
└────────────────────────────────────────────────────────────┘
```

### 4. 直观理解

看一个例子来理解 $\lambda^t$ 到底意味着什么：

```python
# 假设一个帧有 N=1000 个特征

# RANSAC最终选出的最佳位姿 P^t 下:

# 正确预测的特征（内点）:
# r_i < 0.05m → TriMLP预测的全局坐标与位姿+深度反投影一致
# 数量: 850个

# 错误预测的特征（外点）:
# r_i >= 0.05m → 差距过大
# 可能原因: TriMLP还没学会这个区域 / 动态物体 / 噪声
# 数量: 150个

# λ^t = 850/1000 = 0.85
# 含义: 85%的特征与当前地图一致
# 判断: 位姿估计可信度较高（λ>0.5）
#       但不是完美（λ<0.95），有些区域还没学好
```

### 5. 三种典型情况的 $\lambda^t$ 值

| 场景 | $\lambda^t$ | 含义 |
|------|------------|------|
| 相机回到已学过的区域 | 0.95~1.0 | 几乎所有特征都与地图一致。位姿很准，不需要训练 |
| 相机看到一半新一半旧的区域 | 0.4~0.7 | 新区域的特征预测错误（外点），旧区域的特征正确（内点）。RANSAC仍然能靠旧区域的内点找到正确位姿。这个帧需要成为关键帧来学习新区域 |
| 相机突然进入全新场景 | 0.0~0.3 | 几乎所有特征都是外点。RANSAC可能找到错误位姿。非常危险的状态，可能跟踪丢失 |

### 6. 论文中的公式

论文原文公式 (11)-(12)：

$$
\lambda^{t}(\mathbf{P})=\frac{1}{N} \sum_{i=1}^{N} \mathbf{1}\big(r_{i}^{t}(\mathcal{M}, \mathbf{P})<\tau\big)
$$

$$
\mathbf{P}^{t}=\operatorname*{arg\,max}_{\mathbf{P}\in\mathcal{P}^{\mathcal{H}}} \lambda(\mathbf{P})
$$
