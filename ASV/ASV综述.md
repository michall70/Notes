# 挑战
要求探测距离远（弥补机动性不足）

| 特点                       | 为什么难                                                  |
| ------------------------ | ----------------------------------------------------- |
| 稀疏且低纹理的地标                | 陆地上有墙、树、建筑、路标，特征多；海上很多地方是水面、天空、远处岸线，特征少，SLAM 很难匹配     |
| 动态海面                     | 水面一直在动，反光、波浪、尾迹会干扰视觉和 LiDAR，特征不稳定                     |
| 杂波和多径导致传感器退化             | 雷达有海杂波、雨杂波；无线电/雷达波会多次反射，产生虚假目标；相机有眩光、反射；LiDAR 有水面镜面反射 |
| 受限运河和港口环境中 GPS 频繁退化      | 桥、建筑、岸壁、大船遮挡卫星信号，GPS 容易跳变、丢失或多径                       |
| 天气因素（雨，雾），光线             | 相机，毫米波雷达等易受影响                                         |
| 所有这些都要求针对海事条件定制的鲁棒多传感器算法 | 单一传感器不够，必须雷达、LiDAR、相机、IMU、GPS 等融合，并且算法要适应海上特点         |

> 海上 SLAM 不是把陆地 SLAM 搬过来就行，海上特征少、水面动、杂波多、GPS 还容易丢，所以需要专门的多传感器鲁棒算法。**

**地标稀疏、海面动态、杂波多径、GPS 退化 → 需要鲁棒多传感器 SLAM。**

# 算法
```
感知算法
├── 单模态（Uni-modal）
│   ├── 传统方法（Classical）
│   ├── 深度学习（Deep Learning）
│   │   ├── 检测（Detection）
│   │   └── 分割（Segmentation）
│   └── SLAM / 里程计（Odometry）
└── 多模态（Multi-modal）
    ├── 跟踪滤波（Tracking Filter）
    ├── 数据关联（Data Association）
    └── 深度学习（Deep Learning）
```
